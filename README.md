📘 AR Insights Dashboard — Power BI
A compact Power BI dashboard designed to analyze Accounts Receivable (AR) performance, aging, collections, and customer risk. Built with clean modeling, DAX measures, and a modern navy‑themed layout.

🔍 Key Features
AR KPIs — Total AR, Overdue %, DSO

Aging Buckets — 0–30, 31–60, 61–90, 90+ days

Customer Risk Matrix — Exposure vs. days overdue

Collections Trend — Monthly collections performance

Invoice Detail — Drill‑down table with conditional formatting

🧠 Skills Demonstrated
Data modeling

DAX measure development

Finance analytics (AR, billing, collections)

Dashboard UI/UX design

🚀 How to Use
Download the .pbix file

Open in Power BI Desktop

Replace or refresh the dataset

Explore insights
